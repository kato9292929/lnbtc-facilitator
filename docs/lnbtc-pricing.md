# lnbtc の msat 建て価格

x402 の `exact` / `lnbtc` は `amount` をミリサトシの正の整数文字列に限る。`$0.01` や
`1 USD` のような表示は（変換パーサを登録しない限り）拒否される。したがって相場で揺れる
USD 建てを実行時に変換せず、基準レートで一度決めた msat を設定値として持つ。

固定値は `facilitator/pricing.py` の `PRICES_MSAT` にあり、この文書の基準レートからの
再計算と一致することを `tests/test_lnbtc_pricing_auth_credit.py` で固定している。

## 基準レート

```
項目        値
--------------------------------------------------
BTC/USD     84,464.00
出典        Bybit
取得日      2026-09-27
併記        CoinDesk 84,602.39（同日）
```

## 算出式と結果

`msat = ceil(USD ÷ BTCUSD × 10^11)` を 1 sat 単位に切り上げ、最低 1 sat。

```
エンドポイント      USD建て   厳密値(msat)   採用(msat)   sats
-----------------------------------------------------------------
/api/jin/series     $0.01     11,839.36      12,000       12
/api/jin/movers     $0.02     23,678.73      24,000       24
/api/jin/latest     無料      —              —            —
```

1 コールあたりの mainnet 上限は 1,000 sats。12 / 24 sats はいずれも下回る。

## 出典を Bybit にした判断について

v3 指示書は「保守的に低いほうを採った」としている。方向を明示しておく。`msat` は
`USD ÷ BTCUSD` なので、BTC/USD が低いほど msat は大きくなる。つまり低いレートを採ると
受取 sats が増え、購入者の支払いも増える。ここでの「保守的」は受取側の収入が
BTC 下落で目減りしない方向を指す。購入者にとって安全側という意味ではない。

なお、この粒度ではどちらの出典でも結果が変わらない。

```
出典        BTC/USD      $0.01 -> sats   $0.02 -> sats
------------------------------------------------------
Bybit       84,464.00    12              24
CoinDesk    84,602.39    12              24
```

1 sat 単位への切り上げが 138.39 の差を吸収するため、出典の選択が価格を動かさない。
この事実もテストで固定している（`test_both_quoted_sources_round_to_the_same_sats`）。

## 見直し

- 月初。
- 基準値 84,464.00 から BTC/USD が ±30% を超えて乖離した時点。
  判定は `facilitator/pricing.needs_repricing()`。境界の ±30% ちょうどは再計算しない。

再計算したときは、この文書の基準レート・出典・取得日と `PRICES_MSAT` を同時に更新する。
片方だけ変えると、テストが不一致で落ちる（意図した安全弁）。

## この実行環境での制約

BTC/USD スポットをこのセッションから取得することはできない。外向き通信が
パッケージレジストリと `raw.githubusercontent.com` 系に限られているため、
Bybit / CoinDesk の値は指示書に記載されたものをそのまま採り、算術のみを検証した。
レート自体の出典確認は運用者側で行う。
